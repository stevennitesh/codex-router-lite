# Pareto investigation history — 2026-09-17

Use [the active Pareto guide](../agents/pareto.md) for maintained behavior.
This record captures bounded evidence for the initial `openrouter/pareto`
candidate and does not constitute deployment or v2 certification.

## Public metadata

The official [OpenRouter model page](https://openrouter.ai/unbiased/pareto)
identified `unbiased/pareto` as a multimodal composite model from Unbiased with
about 262.1K context and 131.1K maximum output. It advertised max tokens,
temperature, top-p, tools, tool choice, and response formatting, with no
reasoning or parallel-tool control. Pricing shown was $2.50 per million input
tokens, $7.50 per million output tokens, and $0.25 per million cached input
tokens. The page stated no prompt training and 30-day retention.

The endpoint UI pinned the request to only `unbiased` with fallback disabled.
The retired Union endpoint error separately identified its successor as
Unbiased Pareto. Public model-level capability labels were treated as discovery
evidence, not as proof of the exact direct Responses wire contract.

## Bounded direct Responses probes

Eight synthetic requests used `unbiased/pareto`, only the `unbiased` endpoint,
`allow_fallbacks: false`, and `require_parameters: true`, with a 256-token output
cap. No private conversation or project content was sent.

| Probe | Result |
| --- | --- |
| automatic function choice | HTTP 200; produced `synthetic_lookup` |
| literal `none` | HTTP 404; no endpoint supported the tool-choice value |
| `required` | HTTP 404; no endpoint supported the tool-choice value |
| named function choice | HTTP 404; no endpoint supported the tool-choice value |
| reasoning effort | HTTP 404; no endpoint handled the requested parameter |
| text verbosity | HTTP 404; no endpoint handled the requested parameter |
| `parallel_tool_calls` | HTTP 404; no endpoint handled the requested parameter |
| Responses `text.format` JSON schema | HTTP 404; no endpoint handled the requested parameter |

The one successful direct probe reported 162 input tokens, 56 output tokens,
and $0.000825 cost. Rejected probes did not report usage or cost.

The candidate now rejects explicit structured response formats locally with
`unsupported_response_format`; it does not silently remove a caller's JSON
contract. An explicit plain-text format is normalized to the endpoint default.

## Isolated Router proof

Four more synthetic provider requests ran through an isolated candidate Router
and its protected forwarder. They used a namespaced custom tool owned by the
fixture, replayed the produced custom-tool result, compacted that history, and
resumed from the Router-produced compaction output. The observed markers were
`PARETO_REPLAY_OK` and `PARETO_RESUME_OK`; the restored call retained namespace
`synthetic_ns` and name `emit`.

That live compaction probe included a synthetic JSON-object format field which
the initial candidate removed before sending. The corrected candidate rejects
that caller contract locally. The provider-side compaction evidence remains for
the identical outbound request produced without an explicit format; isolated
regressions cover local rejection on both Responses and compaction paths with
zero provider traffic.

The three ordinary responses reported a combined $0.00678675. The Router's
compaction response intentionally reported null usage, so the compaction
request's cost is not included. Across direct and Router evidence, 12 provider
requests were made and the known reported cost was $0.00761175 plus the
unreported compaction request. Cancellation was covered by the isolated
transport regression rather than spending a thirteenth live request.

The proof used no installed-runtime replacement, native tool-definition export,
private task history, deployment, or subagent certification.
